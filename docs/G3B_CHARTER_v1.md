## 3. البذور وضد الاصطياد

- R = رقم جولة drand quicknet **مكتوب حرفيًا عند التجميد** بالصيغة «drand quicknet round R =» متبوعة بالرقم، ووقتها بعد دفع commit التجميد إلى main بساعتين على الأقل (بوقت خادم GitHub)، والتحقق بتوقيع BLS (`g2/drand/verify.mjs`، بنسخ مكتبات مثبتة).
- `seed_base = int(sha256((charter_hex + rand_hex).encode('ascii')).hexdigest()[:16], 16)`، و`charter_hex` بصمة هذا الملف عند commit التجميد.
- العالم: `SeedSequence(seed_base, spawn_key=(STAGE, li, 0, cell, w))`، وتبديلات المحكمة `(STAGE, li, 1, cell, w)`؛ STAGE = 41 للمعايرة و51 للقوة، وli رقم الطول.
- **ضد الاصطياد** (`g3b/verify_anchor.py`، آليًا): commit التجميد هو **أول** commit على main أدخل سطر الجولة؛ `g3b/FREEZE.json` يُنشأ **مرة واحدة** في commit ابن مباشر للتجميد لا يغيّر سواه؛ التجميد يُدفع إلى main **رأسًا لدفعة مستقلة**؛ كل الشجرة تطابق التجميد؛ أي force-push على main يُبطل التشغيل؛ التشغيل يبدأ بالدفع فقط.
- **لا حجب لنتيجة معروفة:** بعد نشر R تصبح البذرة علنية. لذلك يجب دفع `FREEZE.json` إلى main خلال **48 ساعة** من وقت R، وإلا يفشل الفحص. ودفع التجميد إلى main **التزام علني ملزم**: أي ميثاق لاحق يجب أن يذكر هذا الميثاق ونتيجته، أو أنه لم يكتمل.
- **إجراء التجميد:** (1) main يُنشأ أولًا بمسودة لا رقم في سطر جولتها؛ (2) commit التجميد X: الحالة FROZEN، وR بأرقام ASCII بلا فواصل ووقتها بعد الدفع المخطط بـ 3 ساعات على الأقل، و`MANIFEST_SHA256.txt` مُعاد توليده ومفحوص محليًا؛ (3) يُدفع X وحده إلى main؛ (4) بعد R يُدفع commit `FREEZE.json` نفسه الذي اجتاز البروفة.
- **بروفة جافة قبل التجميد:** فرع `rehearsal/dry-*` بنسخة من X بجولة R′ منشورة سابقًا، لاختبار الأنابيب كلها قبل أي التزام. ليست نتيجة بوابة، وبذرتها مختلفة.
- **البروفة:** دفع `FREEZE.json` على فرع `rehearsal/**` يشغّل workflow نفسه: فحص المرساة `--rehearsal`، وشظيتان لكل (نمط، طول)، أي 12 صف معايرة (كل عالم ×2) و30 صف قوة (كل خلية ×2) لكل طول، **ببذرة مختلفة** `sha256("REHEARSAL-"+seed_base)`، ويُشترط أن يكون HEAD ابنًا مباشرًا للتجميد. ليست نتيجة بوابة. يُدفع إلى main **commit البروفة نفسه**.
- كل خطوة تعمل بـ `bash -eo pipefail`، وتُرفض `seed_base` غير الرقمية قبل أي حساب.

## 4. G2b عند كل طول — المعايرة

مطابقة لـ G2b في الميثاق الأصل:
- **العوالم:** N1 وN2 وN2b وN3 وN4 وN5، و10,000 عالم لكل نوع (60,000 لكل طول)، كلها تدخل التقييم.
- **قاعدة FAIL لكل خلية** (12 خلية = 6 × α ∈ {0.05، 0.01}): (أ) binomial أحادي «المعدل ≤ 1.1α» يُرفض عند 0.01/12؛ أو (ب) k > 625 عند 0.05، أو k > 125 عند 0.01.
- **G2b(T) = PASS** ⇔ لا خلية تفشل والسجلات كاملة وإعادة حساب 12 صفًا مختارة بالبذرة تطابق.

## 5. G3 عند كل طول — القوة

- **العالم والقوانين** كما في الأصل: L1 زخم، L2 ارتداد، L3 زخم بنظام ماركوف. β ∈ {0.005، 0.01، 0.02، 0.03، 0.05}، و300 عالم لكل خلية.
- **الحاجز بنسبة المعلومات نفسها:** الفريم M15 لم يتغير، فالحاجز هو **β = 0.01** نفسه (≈ 0.9 نسبة معلومات سنوية قبل التكاليف).
- **G3(T) = PASS** ⇔ القوة عند α=0.01 ≥ **0.80** لـ L1 **ولـ** L2 عند β=0.01. باقي الخلايا وصفية (منحنيات قوة، MDE80، نسب الإسناد).

## 6. القرار وما بعده

| النتيجة عند طول T | الإجراء |
|---|---|
| G2b(T) PASS وG3(T) PASS | يُسمح بدخول الذهب **بهذا الطول بالضبط**: **اختبار محكمة واحد** على **T شمعة M15 صالحة متصلة** (الأحدث)، وفق تعريف «الصالحة» وفحوص الجودة في ميثاق الذهب، المكتوبة قبل فتح أي سعر. أي تقسيم يختبر على شموع أقل من T يُسقط ضمان القوة |
| G2b(T) FAIL | لا ذهب بهذا الطول |
| G3(T) FAIL | لا ذهب بهذا الطول |
| INCOMPLETE | تُعاد الوظائف المتعطلة فقط بالكود والبذرة نفسها |

- **إذا نجح الطولان:** يُستخدم A (500,000) إذا اجتازت بيانات ما قبل 2010 فحوص الجودة، وإلا B (380,000). القرار بقاعدة الجودة وحدها، لا بأي نظرة إلى نتائج الذهب.
- إذا نجح الطول A وحده: الدخول إلى الذهب مشروط بأن تجتاز بيانات ما قبل 2010 فحوص الجودة، وإلا لا يُسمح بدخول الذهب بالقاعدة الحالية.
- إذا فشل الطولان: **بيانات الذهب المتاحة لا تكفي لرؤية قوانين بنسبة معلومات ≈ 0.9 بقوة 80%.** لا تخفيف للحاجز. يُعلن ذلك نتيجةً، ويحتاج أي مسار لاحق ميثاقًا جديدًا بمحكمة أو عائلة ميزات مختلفة ومعايرة كاملة.
- لا إعادة تشغيل ببذور جديدة لأي نتيجة PASS أو FAIL.

## 7. حدود معلنة مسبقًا

- النطاق: المعايرة صالحة لهذه العوالم الستة، عند هذين الطولين بالضبط، وK=10، وH=4.
- العوالم الاصطناعية لا تغطي كل خصائص الذهب (ارتداد الشراء والبيع، الفجوات، تغير المصدر عند 2010). هذا عمل ميثاق الذهب.
- الطولان مُختاران من حجم البيانات المتاح، بعد الاطلاع على PILOT 05 الاستكشافي. ولهذا فإن النتيجة التأكيدية ببذرة جديدة غير معروفة مسبقًا هي الدليل الوحيد.
- **التوقع المعلن مسبقًا (من PILOT 05):** الطول B سيفشل في G3 على الأرجح (قوة L1 ≈ 0.55–0.6)، والطول A قريب من الحد (≈ 0.75). اختبار طولين لا يضخّم شيئًا يُذكر لأن القوة تزيد مع T.
- **ما يجب أن يضيفه ميثاق الذهب:** تعريف الشموع الصالحة والفجوات (العوالم الاصطناعية بلا فجوات، والميزات تعبرها)، ومعالجة وصل المصدرين عند 2010 للطول A، وفحوص الجودة، وارتداد الشراء والبيع، والتكاليف، وكلها قبل فتح أي سعر.
