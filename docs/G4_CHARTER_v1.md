## 3. البذور وضد الاصطياد

- R = رقم جولة drand quicknet **مكتوب حرفيًا عند التجميد** بالصيغة «drand quicknet round R =» متبوعة بالرقم، ووقتها بعد دفع commit التجميد إلى main بساعتين على الأقل (بوقت خادم GitHub)، والتحقق بتوقيع BLS (`g2/drand/verify.mjs`، بنسخ مكتبات مثبتة).
- `seed_base = int(sha256((charter_hex + rand_hex).encode('ascii')).hexdigest()[:16], 16)`، و`charter_hex` بصمة هذا الملف عند commit التجميد.
- العالم: `SeedSequence(seed_base, spawn_key=(STAGE, li, 0, cell, w))`، وتبديلات المحكمة `(STAGE, li, 1, cell, w)`؛ STAGE = 91 للمعايرة و101 للقوة، وli رقم الطول.
- **ضد الاصطياد** (`g4/verify_anchor.py`، آليًا): commit التجميد هو **أول** commit على main أدخل سطر الجولة؛ `g4/FREEZE.json` يُنشأ **مرة واحدة** في commit ابن مباشر للتجميد لا يغيّر سواه؛ التجميد يُدفع إلى main **رأسًا لدفعة مستقلة**؛ كل الشجرة تطابق التجميد؛ أي force-push على main يُبطل التشغيل؛ التشغيل يبدأ بالدفع فقط.
- **لا حجب لنتيجة معروفة:** بعد نشر R تصبح البذرة علنية. لذلك يجب دفع `FREEZE.json` إلى main خلال **48 ساعة** من وقت R، وإلا يفشل الفحص. ودفع التجميد إلى main **التزام علني ملزم**: أي ميثاق لاحق يجب أن يذكر هذا الميثاق ونتيجته، أو أنه لم يكتمل.
- **إجراء التجميد:** (1) main يُنشأ أولًا بمسودة لا رقم في سطر جولتها؛ (2) commit التجميد X: الحالة FROZEN، وR بأرقام ASCII بلا فواصل ووقتها بعد الدفع المخطط بـ 3 ساعات على الأقل، و`MANIFEST_SHA256.txt` مُعاد توليده ومفحوص محليًا؛ (3) يُدفع X وحده إلى main؛ (4) بعد R يُدفع commit `FREEZE.json` نفسه الذي اجتاز البروفة.
- **بروفة جافة قبل التجميد:** فرع `rehearsal/dry-*` بنسخة من X بجولة R′ منشورة سابقًا، لاختبار الأنابيب كلها قبل أي التزام. ليست نتيجة بوابة، وبذرتها مختلفة.
- **البروفة:** دفع `FREEZE.json` على فرع `rehearsal/**` يشغّل workflow نفسه: فحص المرساة `--rehearsal`، وشظيتان لكل (نمط، طول)، أي 12 صف معايرة (كل عالم ×2) و30 صف قوة (كل خلية ×2) لكل طول، **ببذرة مختلفة** `sha256("REHEARSAL-"+seed_base)`، ويُشترط أن يكون HEAD ابنًا مباشرًا للتجميد. ليست نتيجة بوابة. يُدفع إلى main **commit البروفة نفسه**.
- كل خطوة تعمل بـ `bash -eo pipefail`، وتُرفض `seed_base` غير الرقمية قبل أي حساب.
